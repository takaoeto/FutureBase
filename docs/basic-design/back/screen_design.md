# 画面設計

## 1. 画面一覧

| 画面名               | パス           | 内容                 |
| -------------------- | -------------- | -------------------- |
| ログイン画面         | /login         | ログイン             |
| プロジェクト一覧画面 | /projects      | プロジェクト一覧表示 |
| プロジェクト作成画面 | /projects/new  | 新規作成             |
| プロジェクト詳細画面 | /projects/{id} | タスク一覧表示       |
| タスク作成モーダル   | -              | タスク追加           |
| タスク編集モーダル   | -              | タスク更新           |

---

## 2. 画面詳細

---

### 2.1 ログイン画面

### 入力項目

- メールアドレス
- パスワード

### ボタン

- ログイン

### 処理

- POST /api/auth/login
- JWTをlocalStorageへ保存
- /projectsへ遷移

---

### 2.2 プロジェクト一覧画面

### 表示項目

- プロジェクト名
- 作成日
- 編集ボタン
- 削除ボタン

### ボタン

- 新規作成

### 処理

- GET /api/projects
- プロジェクトカード形式で表示

---

### 2.3 プロジェクト作成画面

### 入力項目

- プロジェクト名

### ボタン

- 保存
- 戻る

### 処理

- POST /api/projects
- 作成後 /projects に遷移

---

### 2.4 プロジェクト詳細画面

### 表示項目

- プロジェクト名
- タスク一覧（カンバン形式）

### カラム

- TODO
- DOING
- DONE

### 処理

- GET /api/projects/{id}/tasks
- statusに応じてカラム分け表示

---

### 2.5 タスク作成モーダル

### 入力項目

- タイトル
- 説明
- ステータス（初期値: TODO）

### 処理

- POST /api/projects/{id}/tasks
- 成功後一覧再取得

---

### 2.6 タスク編集モーダル

### 入力項目

- タイトル
- 説明
- ステータス

### 処理

- PUT /api/tasks/{id}
- 成功後一覧再取得
