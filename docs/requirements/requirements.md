# FutureBase 要件定義書

## 1. システム概要

### 1.1 システム名

FutureBase

### 1.2 目的

チーム単位でプロジェクトおよびタスクを管理し、
進捗の可視化と業務効率化を行う。

---

## 2. スコープ

### 本リリース対象

- ユーザー登録（メールOTP）
- ログイン（メールOTP）
- JWT認証
- プロジェクトCRUD（ownerのみ）
- タスクCRUD（ownerのみ）
- ページング

### 本リリース対象外

- 招待機能
- リアルタイム更新
- ファイル添付
- 管理者機能
- 通知機能

---

## 3. 想定利用者

- 個人利用または小規模チーム（同時50人）
- プロジェクト所有者のみ利用可能（他ユーザー共有なし）

---

## 4. 業務ユースケース

### UC-01 ユーザー登録

前提：未登録ユーザー

1. メール・パスワード入力
2. OTP送信
3. OTP入力
4. アカウント有効化

---

### UC-02 ログイン

1. メール・パスワード入力
2. OTP送信
3. OTP入力
4. JWT発行

---

### UC-03 プロジェクト作成

前提：ログイン済み

1. プロジェクト名入力
2. 保存
3. 一覧へ反映

---

### UC-04 タスク管理

1. プロジェクト詳細表示
2. タスク作成
3. ステータス変更（TODO/DOING/DONE）

---

## 5. データ要件

### User

- id
- email
- passwordHash
- locked
- enabled
- createdAt

### Project

- id
- name
- ownerId
- createdAt

### Task

- id
- title
- status
- projectId
- createdAt

---

## 6. 非機能要件

### セキュリティ

- JWT認証
- OTP有効期限5分
- OTP5回失敗でロック
- BCryptハッシュ
- HTTPS必須
- RateLimit（OTP）

### 性能

- 同時利用者50人
- ページング必須

### 可用性

- EC2単一構成（将来冗長化）

### 運用

- traceId付きエラー
- /actuator/health 監視
