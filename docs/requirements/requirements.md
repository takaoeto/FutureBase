# FutureBase 要件定義書

## 1. システム概要

### 1.1 システム名

FutureBase

### 1.2 目的

チームで利用可能なタスク管理アプリを提供し、
プロジェクト単位でタスクの可視化・進捗管理を行う。

---

## 2. 想定ユーザー

- 一般ユーザー（プロジェクト所有者）
- 将来的に管理者権限追加予定（本版では未実装）

---

## 3. 機能要件

### 3.1 認証機能

- ユーザー新規登録（メールOTPによる2段階認証）
- ログイン（メールOTPによる2段階認証）
- ログアウト

### 3.2 プロジェクト管理

- 一覧取得（ログインユーザーがownerのもののみ）
- 新規作成（ownerはログインユーザー）
- 更新（ownerのみ）
- 削除（ownerのみ）

### 3.3 タスク管理

- 一覧取得（ownerのプロジェクトのみ）
- 新規作成（ownerのみ）
- 更新（ownerのみ）
- 削除（ownerのみ）
- ステータス管理（TODO / DOING / DONE）

---

## 4. 非機能要件

### 4.1 セキュリティ

- JWT認証
- HTTPS必須
- BCryptでパスワードハッシュ化
- OTPはハッシュ保存
- OTP有効期限5分
- OTP失敗5回でロック

### 4.2 性能

- 同時利用者50人想定
- ページング対応

### 4.3 可用性

- EC2単一構成（将来冗長化）

### 4.4 運用

- traceId付きエラーレスポンス
- /actuator/healthで死活監視

### 4.5 Secrets管理

- JWT秘密鍵・DBパスワードは環境変数管理
